# Aturan Git Commit dan Push

1. **Persetujuan Pengguna**: Jangan pernah melakukan auto-commit atau auto-push secara otomatis saat ada perubahan kode. Selalu minta izin/persetujuan dari pengguna terlebih dahulu.
2. **Bahasa Pesan Commit**: Jika pengguna telah menyetujui commit dan push ke repositori, gunakan **Bahasa Indonesia** untuk semua pesan commit (`git commit -m "..."`).
